MicroExplore Poster References

  1. Mendix. Pluggable Widgets API.

    https://docs.mendix.com/apidocs-mxsdk/apidocs/pluggable-widgets/

    React widget structure, XML properties and the MPK package.

  2. React. createElement.

    https://react.dev/reference/react/createElement

    Programmatic construction of the custom circuit interface.

  3. MDN Web Docs. Scalable Vector Graphics (SVG).

    https://developer.mozilla.org/en-US/docs/Web/SVG

    Scalable board graphics, pin hit areas and wire paths.

  4. MDN Web Docs. Using Web Workers.

    https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers

    Background browser execution and messages between the simulator and interface.

  5. Arduino. Arduino CLI 1.2 documentation.

    https://arduino.github.io/arduino-cli/1.2/

    Compilation of supported Arduino sketches to firmware.

  6. Wokwi and contributors. AVR8js.

    https://github.com/wokwi/avr8js

    AVR microcontroller execution library. MicroExplore dependency: 0.21.1. MIT license.

  7. Wokwi and contributors. RP2040js.

    https://github.com/wokwi/rp2040js

    RP2040 microcontroller execution library. MicroExplore dependency: 1.4.1. MIT license.

  8. CodeMirror. CodeMirror 6.

    https://codemirror.net/

    Code editor. MicroExplore uses versioned CodeMirror 6 packages for C/C++ and Python.

  9. SparkFun Electronics. Pull-up Resistors.

    https://learn.sparkfun.com/tutorials/pull-up-resistors/all

    Article reader and pull-up circuit shown in the poster. CC BY-SA 4.0.

  10. Anant Agarwal and Jeffrey H. Lang, MIT OpenCourseWare. 6.002 Circuits and Electronics, Spring 2007.

    https://ocw.mit.edu/courses/6-002-circuits-and-electronics-spring-2007/

    Course information displayed in the website. MIT course material: CC BY-NC-SA 4.0.

  11. NIST. NanoFab Tool: Oxford Plasmalab 100 Plasma Enhanced Chemical Vapor Deposition.

    https://www.nist.gov/laboratories/tools-instruments/nanofab-tool-oxford-plasmalab-100-plasma-enhanced-chemical-vapor

    New Home source reading on thin-film fabrication. Equipment photograph: NIST. U.S. government material; attribution retained.

  12. NIST. NIST Researchers Develop Photonic Chip Packaging That Can Withstand Extreme Environments.

    https://www.nist.gov/news-events/news/2026/03/nist-researchers-develop-photonic-chip-packaging-can-withstand-extreme

    New Home source reading on photonic packaging, 30 March 2026. Photograph detail: M. King/NIST, updated 22 April 2026. U.S. government material; attribution retained.

  13. SparkFun Electronics. Analog to Digital Conversion.

    https://learn.sparkfun.com/tutorials/analog-to-digital-conversion/all

    Home-page conversion example and Uno reference photograph. CC BY-SA 4.0.

  14. Arduino. Blink Without Delay.

    https://docs.arduino.cc/built-in-examples/digital/BlinkWithoutDelay/

    Source for LED Blinking Using an Independent Timer. The guide uses elapsed-time scheduling with millis(), rather than delay(). Original example code is public domain.

  15. NIST. NIST Scientists Develop Novel CT Scan Device for Integrated Circuits.

    https://www.nist.gov/news-events/news/2023/04/nist-scientists-develop-novel-ct-scan-device-integrated-circuits

    New Home source reading on integrated-circuit inspection, 14 April 2023. Research-system illustration: Sean Kelley/NIST. U.S. government material; attribution retained.
